║              QUIZ OVERLAY - GUIDE D'UTILISATION                 ║
╚══════════════════════════════════════════════════════════════════╝

📋 PRÉREQUIS
────────────
• Windows 10 ou supérieur
• Node.js installé (télécharger depuis https://nodejs.org/)
• Un navigateur web (Chrome, Firefox, Edge...)
• (Optionnel) Git installé si vous voulez les mises à jour automatiques (LiveUpdate)

🚀 DÉMARRAGE
────────────
1. Double-cliquez sur le fichier "DEMARRER.bat"
2. Si le projet a été cloné avec Git, les mises à jour sont récupérées automatiquement (LiveUpdate)
3. Attendez quelques secondes que le serveur démarre
4. L'interface d'administration s'ouvrira automatiquement dans votre navigateur

🔄 LIVEUPDATE (MISES À JOUR AUTOMATIQUES)
─────────────────────────────────────────
Si vous avez obtenu le projet via "git clone" et que Git est installé, chaque lancement
avec DEMARRER.bat récupère les dernières modifications sur la branche main. Vous êtes
toujours à jour avec les mises à jour du développeur sans rien faire.

✨ UTILISATION
─────────────
• L'interface d'administration vous permet de :
  - Sélectionner la difficulté
  - Choisir une catégorie
  - Tirer un thème aléatoire
  - Lancer des questions
  - Contrôler l'affichage dans OBS

• Pour utiliser dans OBS :
  - Ajoutez une source "Navigateur" (Browser Source)
  - URL : http://localhost:3000/overlay
  - Largeur : 1920
  - Hauteur : 200 (ou selon vos besoins)
  - Fond transparent : Activé

🛑 ARRÊT
────────
• Double-cliquez sur "ARRETER.bat" à la racine du projet (recommandé)
• Ou fermez la fenêtre de commande qui s'est ouverte
• Ou utilisez Ctrl+C dans cette fenêtre

❓ PROBLÈMES COURANTS
─────────────────────
• "Node.js n'est pas installé" :
  → Installez Node.js depuis https://nodejs.org/

• "Le serveur ne démarre pas" :
  → Vérifiez qu'aucun autre programme n'utilise le port 3000
  → Redémarrez votre ordinateur si nécessaire

• "L'admin ne s'ouvre pas" :
  → Ouvrez manuellement : http://localhost:3000/admin
